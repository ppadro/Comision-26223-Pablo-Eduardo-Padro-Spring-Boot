# Ferretería Padró - API de Artículos

REST API hecho con Spring Boot 3.2.5 y MySQL (XAMPP).

## video descriptivo
https://youtu.be/X_3Pm-jiMJ0

## Ejecución
1. Iniciar MySQL en XAMPP y creación de la DB  `ferreteria`.
2. Abrir el proyecto en VSC y ejecutar Run enla clase principal de la aplicación.
3. Probar los endpoints en `http://localhost:8080/api/articulos` con Postman.
